    The technical version

    How listings get on the site. Every submission is saved as pending. The site owner reads it, checks the website and approves or rejects it. Nothing a visitor sends appears until it is approved, and a program has to agree to be listed before it can be approved.

    What stays private. Contact names and emails are kept only for follow-up. They are never shown on the site or returned by the public API (/api/outreach). Each program's answer about funding changes is also private; it only counts toward the totals in the chart.

    Small counts. Any total under 10 is hidden. If only one total would be hidden, the next smallest is hidden as well, so the hidden number can't be worked out by subtracting from the number of programs listed.

    Self-reported. Listings and the funding chart come from the programs themselves. They have not been independently verified, so treat the chart as a picture of who has spoken up, not a measure of every program in the country.

    Spam and safety. The server strips HTML from every answer, ignores submissions that fill a hidden trap field, and limits each connection to 10 tries an hour. It stores a salted hash of the connection, never the IP address, and deletes it after an hour.
